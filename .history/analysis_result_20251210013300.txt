# 垂直原理3D可视化方向分析报告

## 力向量方向分析

### 1. 引力向量 (Gravity)
- **计算方式**：`new THREE.Vector3(-x, -y, -z).normalize()`
- **方向**：指向坐标原点(0,0,0)
- **正确性**：✅ 正确
- **物理意义**：符合引力特性，总是指向质量中心

### 2. 电场向量 (Electric Field)
- **计算方式**：`new THREE.Vector3(x, 0, z).normalize()`
- **方向**：沿x-z平面径向发散
- **正确性**：✅ 正确
- **物理意义**：符合正电荷电场的径向发散特性

### 3. 磁场向量 (Magnetic Field)
- **原代码问题**：`crossVectors(tangent, radial)` 导致方向错误
- **修正后**：`crossVectors(radial, tangent)`
- **方向**：沿y轴负方向
- **正确性**：✅ 正确（修正后）
- **物理意义**：
  - 螺旋线为右手螺旋（t增加时沿y轴正方向延伸，绕y轴逆时针旋转）
  - 径向向量：`(cos(t), 0, sin(t))`（指向外侧）
  - 切线向量：`(-sin(t), 0, cos(t))`（旋转方向切线）
  - 叉积结果：`(0, -1, 0)`（沿y轴负方向）
  - 符合右手螺旋定则：右手握住螺旋，拇指指向磁场方向

### 4. 核力向量 (Nuclear Force)
- **计算方式**：使用随时间变化的三角函数
- **方向**：复杂多变的三维方向
- **正确性**：✅ 合理
- **物理意义**：模拟核力的复杂短程相互作用特性

## 螺旋运动分析

### 螺旋线方程
```javascript
x = config.radius * Math.cos(angle);
y = config.pitch * angle - config.turns * Math.PI * config.pitch;
z = config.radius * Math.sin(angle);
```

### 运动特性
- **旋转方向**：逆时针（绕y轴，从上方看）
- **前进方向**：y轴正方向
- **螺旋类型**：右手螺旋
- **正确性**：✅ 符合垂直原理的几何描述

## 整体结论

所有力向量的方向计算均符合物理规律和垂直原理的理论要求：
- ✅ 引力：指向中心
- ✅ 电场：径向发散
- ✅ 磁场：沿螺旋轴线方向（修正后）
- ✅ 核力：复杂短程力模拟

**修正建议**：已修正磁场向量的叉积顺序，使其符合右手螺旋定则。
