理论解释

1. 质量定义：使用全空间立体角 (4π)

在定义物体（如地球）的内禀质量时，必须考虑其周围全空间的效应。

质量定义方程：m = k · n / (4π)

其中：

  • m：物体的质量
  • k：比例常数
  • n：空间位移矢量的总条数
  • 4π：全空间立体角（整个球面）

质量是物体对其周围所有方向空间运动强度的全局度量，因此必须使用全空间立体角4π。

2. 场通量计算：使用有效半球立体角 (2π)

当计算一个场（如引力场）穿过一个特定平面（如地球表面）的通量时，只有来自平面上方半球空间的场线能穿过该平面。

通量计算的有效立体角：Ω_有效 = 2π

几何因子：4π / 2π = 2

这个因子2出现在理论的关键公式中，如：

Z = Gc / 2

关键区别：4π用于定义源的属性（质量），而2π用于计算该源的场对特定表面的作用。

3. 水龙头与盆的比喻

将引力场想象为一个位于地心的、向所有方向均匀喷水的水龙头：

  • 水向所有方向喷洒（立体角4π）
  • 但放在水龙头上方的盆只能接到向上喷洒的水（立体角2π）
  • 向下喷洒的水（另2π）虽然存在，但落不到盆里

盆接到水的多少，只与向上喷洒的那部分水有关，这就是"有效立体角为2π"的直观含义。

质量定义 (4π)

  • 用途：定义物体的内禀质量
  • 几何：全空间球对称
  • 立体角：4π（整个球面）
  • 物理意义：度量物体对全空间的影响
  • 示例：地球质量 M⊕ = k·n/(4π)

场通量计算 (2π)

  • 用途：计算场对特定平面的作用
  • 几何：半球投影
  • 立体角：2π（上半球）
  • 物理意义：度量场穿过平面的有效部分
  • 示例：地表引力通量计算

几何因子 2

  • 来源：4π / 2π = 2
  • 作用：连接全域理论与局部观测
  • 体现：Z = Gc/2, kₑ = 2Z'/c
  • 意义：三维到二维投影的必然结果
  • 验证：与经典物理测量结果一致
