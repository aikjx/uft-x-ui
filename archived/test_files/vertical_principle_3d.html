💫 四种基本力展示

🌍
引力/惯性力
源自：直线运动分量速度变化 (dV/dt)
→ 方向：指向质量中心或加速度反向
⚡
电场力
源自：直线运动流量变化 (dm/dt)
→ 方向：沿电荷连线，同斥异吸
🧲
磁场力
源自：旋转运动分量变化 (-V·dm/dt)
→ 方向：垂直于速度与磁场平面
☢️
核力
源自：光速矢量方向剧烈变化 (dC/dt)
→ 方向：短程束缚，极强复杂

📐 宇宙大统一方程

F = C·dm/dt - V·dm/dt + m·dC/dt - m·dV/dt
电场力 + 磁场力 + 核力 + 引力/惯性力
